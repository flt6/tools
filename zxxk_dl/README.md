# zxxk_dl

学科网资源下载工具。

## 功能

下载学科网(ZXXK.com)的教育资源，将内容转换为本地HTML文件，支持处理单个文件和RAR压缩包。

## 使用方法

1. 运行 `python main.py`
2. 根据提示输入软件ID
3. 程序将自动下载并转换资源为HTML格式
4. 支持连续处理多个资源

## 特性

- JSON API交互
- 图片URL提取
- HTML格式化处理
- 自动文件命名（基于哈希值确保唯一性）
- 支持RAR压缩包处理
- 连续批量处理

## 输出格式

- 本地HTML文件
- 保持原始内容结构
- 便于离线查看和打印

## 注意事项

- 请遵守网站使用条款
- 仅用于合法的教育资源获取
