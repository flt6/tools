# video

视频剪切工具。

## 功能

使用FFmpeg进行简单的视频剪切，根据用户指定的开始和结束时间提取视频片段，支持无损剪切。

## 使用方法

1. 运行 `python cut.py <视频文件>`
2. 根据提示输入开始时间（格式：HH:MM:SS）
3. 输入结束时间（格式：HH:MM:SS）
4. 程序将生成剪切后的视频文件

## 特性

- 无损视频剪切
- 简单时间区间指定
- 快速处理速度
- 保持原始视频质量

## 依赖要求

需要在指定路径安装FFmpeg：
`E:\green\ffmpeg\bin\ffmpeg.exe`

## 时间格式

输入时间使用标准格式：`小时:分钟:秒`
例如：`00:01:30`（1分30秒）
