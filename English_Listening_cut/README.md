# English_Listening_cut

英语听力音频文件自动分割工具。

## 功能

自动分割英语听力考试音频文件，通过检测静音段落将长音频分割为多个小段，并按照规定格式组织输出文件。

## 使用方法

1. 准备MP3格式的听力音频文件
2. 运行 `python main.py 音频文件.mp3`
3. 程序将在OUTPUT目录中创建结构化的分割文件

## 输出结构

分割后的文件将按以下结构组织：
- BASIC文件夹：基础题目
- 1-5文件夹：按题号分类
- Others文件夹：其他片段

## 特性

- 自动静音检测
- 智能分割算法
- 规范化文件命名
- 结构化输出目录
