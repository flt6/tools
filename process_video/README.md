# process_video

视频时长调整工具。

## 功能

使用FFmpeg调整视频播放速度以达到目标时长，支持加速或减速处理，同时保持视频质量。

## 使用方法

1. 编译C++程序（如果尚未编译）
2. 运行可执行文件
3. 按提示输入：
   - 源视频文件路径
   - 目标时长
   - 输出文件名

## 特性

- 精确时长控制
- 自动速度计算
- 质量保持优化
- 交互式操作界面

## 依赖要求

- FFmpeg和FFprobe需要安装并在系统PATH中
- C++编译器（用于编译源代码）

## 应用场景

- 视频时长标准化
- 网课视频调速
- 媒体内容适配
